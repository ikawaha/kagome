# Examples

This directory contains actual example usage demonstrating how to use the features of `kagome`.

| Directory Name | Description |
| :-- | :---------- |
| [wakati](./wakati) | Example of how to **segment Japanese text into words** using `kagome`. |
| [user_dict](./user_dict) | Example of how to **use a user-defined dictionary** with `kagome`. |
| [tokenize](./tokenize) | Example of how to **analyze a sentence (tokenize) and get the part-of-speech (POS) of each word** using `kagome`. |
| [db_search](./db_search) | Example of how to **work with Japanese text data and perform efficient full-text search** using SQLite3 and `kagome`. |
| [server_docker_graphviz](./server_docker_graphviz) | Example of how to **set up a Kagome server with [Graphviz](https://graphviz.org/) support in Docker**. |
| [wasm](./wasm) | Example of how to **use `kagome` in a WebAssembly (Wasm) environment** such as web browsers. |
| [clib](./clib) | Example of **using `kagome` as a C library (implemented in Go)** from Python and PHP 8 via the C ABI (FFI). |
